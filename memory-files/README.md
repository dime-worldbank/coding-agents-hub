# Memory Files

This folder contains resources for **agent memory files** — structured context files that help coding agents better understand the specific context of your project. 

Memory files are one of the most effective ways to guide agent behavior without repeating instructions in every prompt. However, since they are added to every prompt, it is important to keep memory files concise.

Code agents have been developed by computer scientists for computer scientists who use coding for different tasks. The memory file is a great tool for us researchers to instruct the agent what differs in social science research projects compared to the software engineering or corporate research tasks more prevalent in its training data. 

## Subfolders

### [templates/](templates/)
Curated, ready-to-use memory file templates that reflect best practices for social science research projects. These templates have been reviewed and adapted for the kinds of workflows, data, and tooling common in our field. They are a good starting point for any new project.

### [example-library/](example-library/)
A collection of real-world memory files contributed by teams across the organization. These examples have worked well in practice but have **not** been edited or standardized to serve as templates — they are shared as-is to provide inspiration and reference. Use them to understand how other teams have approached their agent setups, but expect to adapt them significantly for your own context.
