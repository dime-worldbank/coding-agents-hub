# Example Memory Files Library

Remember that these files have not been polished or standardized to serve as templates — they are shared as-is to provide inspiration and reference. Use them to understand how other teams have approached their agent setups, but expect to adapt them significantly for your own context.

If your memory file is working well and you think it could be useful for other teams, please consider sharing it with [Impact Analytics](mailto:dimeanalytics@worldbank.org) to be added to this library! Our field needs to build up a shared set of resources and best practices for agent memory files. 

Since these files contain domain-specific information, the big AI companies won't do it for us, or at least not as well as we can do for ourselves. We need to share and build this library together.
