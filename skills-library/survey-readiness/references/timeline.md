# Rollout timeline review

**Basis:** DIME Wiki *Survey Pilot* and *Questionnaire Design*; Impact Analytics survey review resources (stage timings from 2017, kept for now).
**Documents:** timeline or Gantt from questionnaire development to the start of fieldwork, with owners.
**Rule:** judge only dates and dependencies the document states. Reference ranges are DECDI planning guidance, not rules.

| ID | What to check | Severity | Fix |
|---|---|---|---|
| TIME-001 | Ethics approval comes before any contact with respondents (including the pilot); questionnaire frozen before translation | Blocker | Re-sequence |
| TIME-002 | Time to revise and re-test the instrument after the pilot | Important | Add revision and re-test time |
| TIME-003 | Every stage is present: questionnaire design, ethics approval, pilot, translation, programming, procurement, training, fieldwork | Important | Add missing stages |
| TIME-004 | Every stage has a named owner | Important | Assign owners |
| TIME-005 | Buffer for delays in approvals, procurement, access, or equipment, larger in difficult contexts (fragile, remote, insecure) | Important | Add contingency |
| TIME-006 | Stage durations are plausible against DECDI reference ranges: pre-pilot 1-2 weeks, questionnaire design about 4, content testing 2-3, review sessions 1-2, translation 2-3, programming 4-6, data testing 2-3, training about 2 | Important | Extend or justify shorter periods |
| TIME-007 | Review materials are submitted early enough. 2017 minimums before survey start: hiring documents (TOR) 12 weeks, pilot plan 8, questionnaire content 6, programming 4, training manual and schedule 4, field plan and back-check protocol 2, data check protocol and code before start | Important | Move submissions earlier |
| TIME-008 | Fieldwork avoids harvest, rainy season, holidays, elections, school terms, or other known constraints | Important | Shift or plan around |
| TIME-009 | Procurement lead time precedes every stage that depends on the firm | Important | Move procurement earlier |
| TIME-010 | Deadlines match those in the TOR, pilot plan, and field plan | Important | Reconcile documents |
| TIME-011 | Pilot starts roughly 4 to 6 months before launch so findings can change the instrument and protocols (suggested) | Minor | Start earlier where possible |
| TIME-012 | Field test (practice interviews at the end of training) is not counted as the pilot. For a survey that has not been in the field before, a pilot is strongly suggested | Minor | Plan a separate pilot |
| TIME-013 | Ethics application, programming, and the data test run in parallel where possible | Minor | Overlap them |
| TIME-014 | Post-field milestones and owners: raw data delivery, cleaning, quality checks, documentation | Minor | Add them |

**Ask if missing:** target start of fieldwork; any fixed deadline; whether the instrument is new, adapted, or a follow-up; whether the survey has been fielded in this context before.
