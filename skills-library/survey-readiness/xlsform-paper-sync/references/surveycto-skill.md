# The SurveyCTO skill

SurveyCTO publishes its own agent skill, which knows SurveyCTO syntax and has an XLSForm template. See `links.md`.

## When it is required

- **Creating or changing a form: required.** If no SurveyCTO skill is installed, say so in one line and stop. Tell the team where to get it. Do not draft a form without it.
- **Reviewing, comparing, or making a paper version: not needed.** Say nothing about it.

## How to use it

- Load it before writing or editing any form row. Follow it for field types, expressions and the template.
- SurveyCTO notes that agents may skip its skill. If you did not load it, load it now.
- Where this skill's conventions differ from the SurveyCTO skill's general guidance, follow this skill for project conventions (for example the Style Guide codes, if the team chose them) and the SurveyCTO skill for whether syntax is valid. Name the conflict in the report.
- If current SurveyCTO behaviour needs checking and web search is available, check docs.surveycto.com.
