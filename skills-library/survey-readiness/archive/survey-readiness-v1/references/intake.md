# Intake

Ask for these once, in a single message, skipping anything the documents already answer.

**Project:** name, unit, project code, country, survey name.
**Purpose:** survey objectives (up to 3); most important indicators with a short description; main output (impact evaluation report, poverty assessment, project baseline, etc.); other data sources used alongside (administrative, complementary primary, qualitative).
**Design:** is the sample already designed; expected sample size; sampled unit (household, firm, classroom, etc.); target respondent; is this a baseline.
**Who collects:** a firm procured by the World Bank (Bank-executed); a firm procured by the government, a ministry, or a national statistics office (recipient-executed); other. Also ask the contract value if a single source is planned.
**Pilot and timing:** is a pilot planned and when; anticipated start of data collection.
**Mode:** electronic or paper; software.
**Feedback wanted:** any particular area the team wants feedback on. Weight the review toward it.

**Documents to request (if available):** project concept note or similar; sampling strategy; pilot field plan; enumerator and/or supervisor manual; data collection timeline; survey TOR; survey field plan; draft questionnaire.

Record answers in the report header. If an answer changes which criteria apply (for example, a follow-up survey with no major changes from baseline may start the pilot at the data-focused stage; a government-led survey has no TOR to procure), say so and skip those criteria rather than reporting them as failures.

## Ask by area

Ask only the fields that area needs.

| Area | Fields |
|---|---|
| Timeline | start date; pilot timing; who collects; baseline or follow-up |
| Ethics and data security | country; Bank-procured data collection?; respondent type (minors?); audio audits, images, or GPS; software; form already on the server? |
| Sampling | sample designed; sample size; sampled unit; target respondent; baseline |
| Hiring a survey firm | Bank-executed or recipient-executed; contract value; competitive or single source; sample size; start date; mode |
| Pilot plan | pilot timing; new, adapted, or follow-up instrument; mode; software; plan for recording changes |
| Questionnaire design | objectives; indicators; main output; other data sources; target respondent |
| Survey programming | software; mode; has the form passed the server test; is Stata available |
| Training and field plan | who collects; start date; sample size; who writes the field plan |
| Data quality plan | mode; software; who collects; paradata recorded |
