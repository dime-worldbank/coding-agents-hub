# Data Quality Assurance Plan (TEST DOCUMENT, invented project)

## Risks
Enumerator error is the main risk.

## Back-checks
The survey firm will back-check 10% of interviews, selected at random across all enumerators.

## Checks run on incoming data
- Duplicate household IDs.
- Outliers in numeric fields.
- Weekly count of submissions per enumerator.

## Responsibilities
The data manager will review the checks weekly. Feedback goes to enumerators by phone during interviews when problems are found.

## Tools
Checks are run in a spreadsheet.
