# DECDI Coding Agent Hub
A centralized repository that hosts or links to material helping teasm to get started and improve their workflows with coding agents.

## Content

### [skills-library](skills-library/README.md)
Curated catalog of agent skills across topics and languages, including internal and external resources plus installation and update guidance.

### [templates](templates/README.md)
Reusable starter files for teams, including project memory files, skill templates, and configurable agent rules.

### [trainings](trainings/README.md)
Training and enablement content for onboarding and upskilling teams on coding-agent workflows.

### [guides](guides/README.md)
Practical setup and usage guides, with tool references and operational playbooks.

### [external-resources](external-resources/README.md)
Collection of external prompt libraries, cookbooks, and reference material relevant to coding-agent adoption.
